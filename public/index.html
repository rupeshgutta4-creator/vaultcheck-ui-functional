How this works

Strength

Computed locally from character-class diversity, length, and a scan for common patterns — all thresholds above are live parameters, not hardcoded. Nothing is transmitted for this part.

Offline breach check

Your password is hashed with SHA‑1 in your browser and checked against a bundled dataset of 99,838 hashes from the UK NCSC's top breached-password list (via SecLists, MIT licensed). This works with zero network access.

Optional live check

If enabled, a 5‑character hash prefix (never the full password) is sent to your own server, which relays it to the HaveIBeenPwned range API for broader coverage — supplementing, not replacing, the offline check.

VaultCheck — a client-side security utility. Offline dataset: NCSC top 100k passwords via SecLists (MIT). Not affiliated with Have I Been Pwned.
